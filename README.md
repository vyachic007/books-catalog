# BooksLab7

Простое веб-приложение для управления библиотекой книг с использованием Spring Boot, Thymeleaf и PostgreSQL.

## Описание

Приложение позволяет:
- Просматривать список всех книг в библиотеке
- Добавлять новые книги с указанием автора, жанра, года издания и места хранения
- Удалять книги из библиотеки

## Технологии

- **Java 17+**
- **Spring Boot 3.x**
- **Spring Data JPA**
- **Thymeleaf**
- **Bootstrap 5**
- **PostgreSQL**
- **Maven**

## Требования

- Java 17 или выше
- PostgreSQL
- Maven 3.6+
